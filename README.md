# php-form-practice

## 概要

COACHTECH 教材 Tutorial 7-4「フォームとデータ受け渡し ハンズオン演習」で作成した成果物です。
入力→確認→完了の3ステップで動作するユーザー登録フォームを作成しました。
3つのPHPファイルを連携させて、データを受け渡す処理を実装しました。

## 使用技術

- PHP 8.2.32
- HTML5（フォーム要素）
- Docker
- VS Code

## 学んだこと

### practiceで学んだこと

- `form`、`input`、`button`、`action`、`method` など、HTMLの演習で一度学んだ内容を復習し、フォームの中でより実践的に使う方法を学んだ。
- `method="post"` で送信したデータを `$_POST` で受け取り、`name` 属性で指定した名前を使って、それぞれの入力データを取り出せることを学んだ。
- `hidden` を使うことで、画面上には入力欄を表示せずにデータをフォーム内に持たせ、次のPHPファイルへのPOST送信に含められることを学んだ。

### sampleで学んだこと

- `required` や `min`、`max` を指定することで、PHPで処理を書く前にブラウザ側で未入力や入力値の範囲をチェックできることを学んだ。
- `history.back()` を使うことで、`input.php` を新しく開き直すのではなくブラウザの履歴から前の画面に戻れるため、入力した内容を保持したまま戻れることを学んだ。
- `type="submit"` は `form` で指定した送信先へデータを送るためのボタンであり、データを送信したくない場合は `type="button"` を使う必要があることを学んだ。また、`onclick="history.back()"` を設定することで、フォームを送信せずに前の画面へ戻れることを学んだ。
- データを送信する必要がなく、単純に別のページへ移動するだけの場合は、`form` と `submit` を使わず、`a href="..."` を使うことで目的に合ったシンプルな実装ができることを学んだ。

### 動作確認

- リポジトリをダウンロードします。
- Dockerコンテナを起動します。
- ブラウザで `input.php` を開きます。
- 入力画面が表示されるので、名前・メールアドレス・年齢を入力して「確認画面へ」をクリックします。
- 確認画面に、入力した名前・メールアドレス・年齢が正しく表示されていることを確認します。
- 「戻る」をクリックすると、`input.php` に戻ることを確認します。
- 再度入力して確認画面へ進み、「登録する」をクリックします。
- 完了画面に、入力した名前とメールアドレスを使った登録完了メッセージが正しく表示されることを確認します。
- 「最初に戻る」をクリックすると、`input.php` に戻ることを確認します。

## 学習ログ

### 困ったこと

- `hidden` の役割がよく分からず、なぜ確認画面で使用する必要があるのか、使うことで何ができるのかをイメージするのに苦戦した。
- HTML要素や処理について、どこからどこまでを一つのまとまりとして記述すればよいのか判断するのに苦戦した。特に、送信先の異なる「戻る」と「登録する」のボタンをどの `form` に入れるべきか迷った。

### 解決方法

- `input.php` → `confirm.php` → `complete.php` とデータがどのように移動するのかを順番に整理し、確認画面で受け取ったデータを次のPHPファイルへもう一度送るために `hidden` を使用していると理解した。
- それぞれの `form` が「どこへ何を送るためのまとまりなのか」を考え、「登録する」は `complete.php` へデータを送るフォーム、「戻る」は `input.php` へ戻るフォームとして分けて記述した。

### 学んだこと

- `hidden` を使うと、画面上には入力欄を表示せずにフォーム内にデータを持たせ、次のPOST送信に含められることを学んだ。
- コードを書くときは一行ずつ考えるだけでなく、「この処理は何をするためのまとまりなのか」「どこへデータを送るのか」という役割ごとに整理して考えることが大切だと学んだ。
